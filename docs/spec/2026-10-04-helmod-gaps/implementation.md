# 实施补充：对照验收与可观测性

日期：2026-10-05。此补充优先于原规格中的渲染非目标。

## 范围与顺序

先更新规格，再实施阶段 1–7（含 P2 温度），通过测试后按阶段提交；最后实现并单独提交离线 HTML 查看器。不部署网站、不修改正在游玩的存档或 mods。

## Helmod 对照

以本机安装的 helmod_2.2.14.zip 为可复现基准，记录 SHA256 与源码位置。原规格提到的 master 版本不作为可复现基准。测试分三类：Helmod 源码公式或实际执行结果对照、独立闭式合成验收、真实 Nullius 原型集成。清楚标识证据类型，不能把 LP 与自身矩阵求解器相等称为 Helmod 实测一致。

对照涵盖配方速率、概率产物、产能插件、速度/能耗插件、信标、燃料热值与灰、发电效率、热源及相邻加成、太阳能系数、区块引用与份数。Helmod 的路线选择与 LP 的优化目标不同，只在固定配方、机器、插件、燃料、温度与出力系数一致时比较数值。收集缺电、错误燃料、引用环、温度不兼容、整数约束及不可行诊断等反例。

## 可观测性验收

- 版本化图数据保留默认关闭；图必须显示实际达成流量，不把不可行的请求量画成已实现的流。
- 工厂净输出包含尚待处置的副产物；图中拆分为最终输出与处置，不能重复计数。
- 离线 HTML 查看器通过 CLI 将 solve_production / plan_solve 的 JSON 结果渲染为单文件，无服务端、无 CDN、无新增 Python 依赖。
- 页面显示求解状态、请求与达成、能源/机器汇总、可搜索的产线与物料表、带方向和速率的流程图、区块引用与详情；支持打开新 JSON、区块切换、节点检查以及缩放。
- 将真实 Nullius 示例导出到本地 artifacts，提供可直接打开的 HTML 路径与复现命令。数据来自本次求解，标示快照与风光等假设。
- 图数据中不写坐标或颜色，渲染器纯读取结果。Mermaid/DOT 保留字段仍按原约定拒绝；HTML 是独立导出命令。
- 自动测试检查转义、图守恒、稳定 ID、单位、重复渲染与离线资产；浏览器检查加载、筛选、区块切换、节点检查及脚本错误。

## 实施中核实的原型差异

- 本机 mods 已是 Nullius 2.0.11；测试采用已有兼容导出快照，不改动运行环境。
- Nullius 涡轮发电机为隐藏辅助实体，按 scripts/turbine.lua 映射到涡轮制造物品校验。求解行显示两个内部容量，不能视作两种需购买设备；报告显式注明。
- solar-flux 没有 fuel_value，集热器按流体输入量建模；电驱动热存储器必须计入电输入，不能作为免费热源。
- 温度明细保留在物料键中，额外提供按基础物料分组的 temperatures 字段，避免图中把不兼容温度合并。温度匹配行计零设备、零成本，不进入可固定的实体产线清单。
- 阶段 4–5 合并为一个能源提交，因为能源边界、原型来源与真实链验收共同构成可用的能力。


## Helmod 概率产能兼容

执行 Helmod 2.2.14 的 Product:getBaseAmount 后发现：amount=4、probability=0.5、ignored_by_productivity=1、产能+50% 时，Helmod 输出 2.5，而现有模型输出 2.75。官方文档没有直接给出此组合的期望公式，不将此发现解释为游戏实测结果。

新增 defaults.productivity_model / lines[].productivity_model：expected（默认，保持原算法）或 helmod（先乘概率再扣 ignored_by_productivity，与该版 Helmod 一致）。产线输出回显并在 pin 后保留；温度拆分使用同一算法。对照测试同时断言兼容值与旧值，不以已知差异冒充一致。


内部涡轮能量按开式/闭式和等级隔离为 fluid:nullius-energy~<type>-<tier>，不允许默认导入。防止 LP 将闭式配方配到开式隐藏发电器的效率；回归测试检查每个实际选中生成器的内部通道与涡轮类型/等级对应。
